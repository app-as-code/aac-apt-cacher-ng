## About

Apt-Cacher NG is a caching proxy for Debian and Ubuntu package repositories. Hosts on the
local network point their APT configuration at the proxy. Each package is downloaded from
the internet once and then served from the local cache to every other host, which saves
bandwidth and speeds up installs and upgrades.

Key features (as provided by upstream):

- Caches APT repositories for Debian, Ubuntu and derivatives
- Transparent to clients: only the proxy address has to be set in APT
- Built-in status report page for checking cache usage
- Low resource footprint, suitable for small servers

## Quick start (Docker Compose)

The Compose file is rendered from `service.yml` by the App-as-Code template engine. For a
manual run, the external networks used for routing must exist first:

```bash
docker network create services-secured
docker network create services-exposed
docker network create docker-default   # only if it does not exist yet

docker compose up -d
```

The service has no secrets, so no `.env` or `stack.env` file with credentials is required.

## Configuration

Environment variables (defaults from `service.yml`; `CHANGE_ME` must be set per deployment):

| Variable | Default | Description |
|---|---|---|
| `TZ` | `Europe/Berlin` | Time zone of the container |
| `PUID` | `1000` | User ID the container runs as |
| `PGID` | `1000` | Group ID the container runs as |
| `SERVICE_NAME` | `aac-apt-cacher-ng` | Service name used by the template engine |
| `SERVICE_HOSTNAME` | `apt-cacher-ng` | Container hostname |
| `SERVICE_DOMAIN_NAME` | `CHANGE_ME` | Domain name used for the routed hostname |
| `SERVICE_IMAGE_NAME` | `sameersbn/apt-cacher-ng` | Image name |
| `SERVICE_IMAGE_TAG` | `CHANGE_ME` | Image tag; `3.7.4-20220421` is the tag pinned in `service.yml` |

Ports:

| Port | Protocol | Description |
|---|---|---|
| `3142` | TCP | Apt-Cacher NG HTTP proxy and status page (`/acng-report.html`) |

Volumes:

| Volume | Container path | Description |
|---|---|---|
| `cache` | `/var/cache/apt-cacher-ng` | APT package cache |

Client configuration example (`/etc/apt/apt.conf.d/02proxy` on a Debian or Ubuntu host):

```
Acquire::http::Proxy "http://<proxy-host>:3142";
```

## Deploy with App-as-Code

The Docker Compose file, Traefik labels, AutoDNS entries and Homepage entry are generated by
the App-as-Code template engine from `service.yml`. Change the deployment by editing
`service.yml`, not the generated files. Releases are published under
<https://github.com/app-as-code/aac-apt-cacher-ng>.
